# Exploratory Data Analysis (EDA)

**Last Edit:** October 20, 2026 <br>
**Status:** Completed <br>

## Overview

This project focuses on performing Exploratory Data Analysis (EDA) as part of the IBM Machine Learning Professional Certificate. The objective is to understand the dataset, identify patterns, detect anomalies, and uncover meaningful insights that can support subsequent machine learning workflows.

EDA is a critical step in the data science lifecycle, helping transform raw data into actionable knowledge through statistical analysis and visualization.

---

## Objectives

- Understand the structure and characteristics of the dataset.
- Assess data quality and identify missing values.
- Explore feature distributions and relationships.
- Detect outliers and unusual observations.
- Generate visual insights using charts and statistical summaries.
- Prepare the dataset for future machine learning tasks.

---

## Technologies Used

- Jupyter Notebook

---

## EDA Workflow
1. Data Collection
- Load and inspect the dataset.
- Review data types and feature descriptions.

2. Data Cleaning
- Handle missing values.
- Remove duplicates.
- Correct inconsistent formatting.

3. Statistical Analysis
- Descriptive statistics.
- Distribution analysis.
- Correlation analysis.

4. Data Visualization
- Histograms
- Box plots
- Scatter plots
- Correlation heatmaps
- Pair plots

5. Insights & Findings
- Identify key trends and relationships.
- Highlight important variables.
- Document potential issues and recommendations.
- Sample Analysis Questions
- What are the main characteristics of the dataset?
- Are there missing or inconsistent values?
- Which features show strong correlations?
- Are there any significant outliers?
- What patterns emerge from the visualizations?
